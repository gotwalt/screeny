# The faces, and where they came from

`data.rs` is generated by `tools/art-faces.py` and holds the *digits* of four
typefaces as bitmaps, plus one face drawn here. **This repository is intended
to be public**, so a face is only embedded when its own licence allows
redistribution - stated in the font file itself or in its own repository, read
and copied below, not assumed. A face that is "free for personal use" only, as
much of dafont is, is not committed however good it looks; see *Adding a face
locally* at the end.

The bitmaps are **unmodified extracts** of the digits `0`-`9` and, where the
font has one, the colon (card 175). Every glyph is sliced out of the font's own
cell with the box the ten **digits** share, so a colon keeps the position,
weight and baseline the font gave it relative to them. Nothing is redrawn,
hinted, restyled or renamed: the choice on the page is named after the font it
reproduces because it *is* that font's digits, which is the one case OFL 1.1
clause 3 leaves alone (it restricts Reserved Font Names on **modified**
versions).

| Face on the page | Source | Native | Scale | Glyphs | Licence |
|---|---|---|---|---|---|
| **Vesta** | `crates/art/src/faces/stroked.rs` | stroked paths | - | `0-9` | this repository |
| **Terminus Bold** | `bitmap/terminus-font-4.39/ter-u32b.bdf` | 13 x 20 | x1 | `0-9 :` | SIL OFL 1.1 |
| **Terminus** | `bitmap/terminus-font-4.39/ter-u32n.bdf` | 12 x 20 | x1 | `0-9 :` | SIL OFL 1.1 |
| **Spleen** | `bitmap/spleen/spleen-16x32.bdf` | 12 x 20 | x1 | `0-9 :` | BSD 2-Clause |
| **Dina** | `bitmap/dina/Dina_r400-10.bdf` | 6 x 9 | x2 | `0-9 :` | MIT |
| **Micro Grotesk** | `fonts/MicroGrotesk[wght].ttf`, wght 400 | outline | 4 samples/LED | `0-9` | SIL OFL 1.1 |

**Micro Grotesk has no colon**, and that is declared in `tools/art-faces.py`
rather than detected: rasterising one gives the `.notdef` box, a rectangle a
quarter taller than the digits, and asking a TTF for its cmap needs `fontTools`,
which is not a dependency here. `Vesta` declares the ten digits for the same
reason - the colon vesta draws beside them is the patch's own pair of dots, not
a glyph. A patch asks a face for a glyph by `char` and gets nothing at all for
one it has not got, which is how both of those fall back cleanly.

The BDF paths are inside a clone of <https://github.com/Tecate/bitmap-fonts>
(a catalogue; the fonts are not its maintainers' work). Micro Grotesk is
<https://github.com/eliheuer/micro-grotesk>. `data.rs`'s header records the
commit of each clone the current data was cut from, and each `Face`'s `source`
field repeats it per face.

## Terminus Font - SIL Open Font License 1.1

`ter-u32b.bdf` and `ter-u32n.bdf` carry it in the file itself:

```
COPYRIGHT "Copyright (C) 2014 Dimitar Toshkov Zhekov"
NOTICE "Licensed under the SIL Open Font License, Version 1.1"
```

Upstream: <https://terminus-font.sourceforge.net/>. **Reserved Font Name:
"Terminus Font".** The digits here are the Original Version's, unmodified, so
naming the choices "Terminus" and "Terminus Bold" is not a Modified Version
using the Reserved Font Name. If anyone ever redraws one of these bitmaps, the
choice has to be renamed.

## Micro Grotesk - SIL Open Font License 1.1

From `OFL.txt` in <https://github.com/eliheuer/micro-grotesk>:

```
Copyright 2020 The Micro Grotesk Project Authors
(https://github.com/eliheuer/micro-grotesk)
```

No Reserved Font Name is declared after that copyright statement. The face is
rasterised from the variable TTF at weight 400 and **condensed to 0.80** so
that a full-height numeral fits a 14-LED module - at true proportions its `4`
is 14 LEDs wide at 19 LEDs tall and fills the module edge to edge. That is a
change to the *rendering*, not to the font, and the choice is named after the
font it renders; if it is ever given a name of its own, name it something else.

## Faces that were looked at and not embedded

Several good-looking faces in the Tecate catalogue carry **no** `COPYRIGHT` or
`NOTICE` property in the BDF, and the catalogue ships no licence files, so
their terms could not be read: `cherry` (a warm 6 x 9 that would have been a
second chunky face), `gohufont`, `haxor`, `boxxy`, `sq`, `ctrld-font`,
`zevv-peep`, `kourier`. Whatever those terms turn out to be, "probably fine"
is not a licence, and this repository is going public. `uw-ttyp0`'s `t0-22`
*was* readable but its digits are oldstyle figures, which is not a clock face.

## Adding a face locally

A face that may not be redistributed can still be used on your own panel: add
an entry to `FACES` in `tools/art-faces.py` pointing at the font on your own
disk, re-run it, and **do not commit the regenerated `data.rs`**
(`git update-index --skip-worktree crates/art/src/faces/data.rs` keeps it out
of the way). The choice appears on the page like any other. Committing it would
publish the font, which is exactly what the licence you have not got does not
allow.
