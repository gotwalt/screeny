# Home Assistant app: Screeny

Generative art on a Tidbyt LED panel, and the panel as a Home Assistant device.

- Add `https://github.com/gotwalt/screeny` as an app repository, install **Screeny**.
- Opens from the sidebar through Home Assistant's ingress; not on your network
  unless you turn **Direct access** on.
- MQTT is configured by Home Assistant itself.

See [DOCS.md](DOCS.md). The design is `docs/design/home-assistant-app.md`.
