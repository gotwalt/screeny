Screeny

Install the firmware

Turn a Gen 1 Tidbyt into a network display. Plug it in, save a backup of its original firmware, click Install, pick your WiFi. Nothing to download and nothing to type into a terminal.

1. Back up the original firmware

Tidbyt does not publish its firmware, so this copy is the only way to put your Tidbyt back the way it came. It reads the whole chip (8 MB) and saves it as a file. It changes nothing on the Tidbyt.

Allow about eight minutes. Keep the file somewhere safe and private: it also holds the WiFi password the Tidbyt was using.

2. Install

This browser cannot flash a device. Open this page in desktop Chrome, Edge or Opera. Flashing needs a secure page. Open this page from its https address.

Allow about three minutes. Do not unplug the Tidbyt while the bar moves.

You need

  • Desktop Chrome, Edge or Opera. Firefox, Safari and phones cannot talk to USB serial devices.
  • A USB-C data cable. Some charging cables carry power only; if the Tidbyt does not appear in the port list, try another.
  • A Tidbyt Gen 1 (the wooden one). Gen 2 is untested.
  • Your WiFi name and password (2.4 GHz).

What happens

  1. Plug the Tidbyt into your computer and click Back up. Pick the port that appears (CP2102 or USB Serial). Your browser saves the backup file when the read finishes.
  2. Click Install and pick the same port.
  3. The dialog installs the firmware. A first install on a Tidbyt running its original firmware erases the chip first, so nothing old gets in the way. Updating a Tidbyt that already runs screeny keeps its WiFi.
  4. When it finishes, the dialog offers to connect the Tidbyt to WiFi. Type the network name and password. They go straight to the Tidbyt over the cable.
  5. The panel joins your network and appears in the Screeny app in Home Assistant, or on any machine with screeny discover.

If the dialog says it failed to initialize, unplug and replug the cable and try again.

Going back

Choose the backup you saved in step 1 and write it back. The Tidbyt returns to exactly what it ran when you saved it, WiFi included.

Allow about five minutes.
